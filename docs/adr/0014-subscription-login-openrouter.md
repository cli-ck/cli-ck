# OpenRouter Subscription Login

We decided to let users connect OpenRouter by logging in with their OpenRouter account (OAuth PKCE) as an alternative to pasting an API key, surfaced as a new "Subscription Login" tab alongside the existing "Providers" tab in Models settings. The connection is stored in the same OS-keyring-backed credential path as a pasted key and makes OpenRouter equally usable everywhere else in the app (default model, tiers, autocomplete); a per-provider switch lets a user pick key vs. login when both exist. Login opens OpenRouter's real login page in the browser and cli-ck captures the redirect automatically via a short-lived local listener, with a paste-the-code fallback. This ships first because OpenRouter's own terms explicitly support this kind of delegated login, so it carries no platform risk.
