# Claude Pro/Max Subscription Login (via the installed Claude CLI)

We decided to cover Claude Pro/Max not by running our own OAuth login and impersonating the official Claude Code client (mimicking its headers and attestation signals to pass as a first-party request), but by detecting an already-installed, already-logged-in `claude` CLI on the user's machine and routing requests through it directly, reusing the external-agent process infrastructure from [[0012-ai-agent-meta-orchestration]]. The impersonation approach was rejected outright: it is not a login flow, it is software built specifically to defeat Anthropic's technical anti-abuse detection for third-party clients, which Anthropic has actively enforced against since April 2026, and that is not something we build regardless of the consenting user's own account risk, since the party being evaded is not the one consenting. Delegating to the real `claude` binary uses Claude exactly the way Anthropic's terms allow, through their own official client, so it carries none of that risk and needs no warning dialog. This option only appears in the Subscription Login dropdown when `claude` is actually found on PATH; when it is not, Claude stays available the normal way, by pasting an Anthropic API key in the Providers tab.
