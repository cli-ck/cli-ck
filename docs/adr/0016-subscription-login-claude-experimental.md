# Claude Pro/Max Subscription Login (experimental, gated)

We decided to offer Claude Pro/Max subscription login as a third Subscription Login option, built and shippable independently of [[0014-subscription-login-openrouter]] and [[0015-subscription-login-codex]] so it can be pulled out on its own if needed. Because Anthropic actively blocks and can ban a user's own account for reusing a Claude subscription outside Claude's own apps (enforced since April 2026), selecting "Claude Code" in the dropdown shows a one-time warning dialog the user must acknowledge before the login button appears; this consent step is unique to this provider and not applied to OpenRouter or Codex. This keeps the feature available to users who knowingly accept the risk, without exposing it as a default, unlabeled option.
