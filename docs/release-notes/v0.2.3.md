# Oz v0.2.3

## Easier installation of unsigned test builds

- `cli-ck install` and `cli-ck uninstall` install the application where each operating system expects it: `/Applications` on macOS, a Start Menu shortcut on Windows, and a desktop entry on Linux.
- macOS installation removes the quarantine marker and repairs the ad-hoc signature, resolving the damaged-app Gatekeeper error on Apple Silicon.
- Windows installation clears Mark of the Web to reduce SmartScreen friction.
- The launcher starts cli-ck detached, so the terminal is free after launch.

## Documentation

- The README now explains how to install unsigned test builds on macOS, Windows, and Linux.
