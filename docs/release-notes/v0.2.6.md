# cli-ck v0.2.6

## cli-ck branding

- The app, Settings About page, bundle identifier, GitHub link, and website now consistently use the cli-ck name instead of legacy Oz metadata.
- The About page surfaces failures when opening external links instead of silently ignoring them.

## Installation reliability

- The npm launcher and GitHub-release ZIP downloads now use the correct `cli-ck_*` artifact names, so `npm install -g @codecollab.co/cli-ck` finds the expected binaries.
