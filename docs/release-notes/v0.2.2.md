# Oz v0.2.2

## Highlights

- Command Palette adds a fuzzy launcher for quick actions, in-file search, and command history.
- Block-mode Terminal brings GPU-accelerated, Warp-style command blocks and a unified shell and AI input.
- Spaces let you create, rename, and rearrange persistent groups of tabs.
- Built-in viewers open images, audio, video, PDFs, and Markdown without leaving the workspace.
- The file explorer gains drag and drop, Git decorations, and live filesystem updates.

## Also included

- Zen mode, configurable editor auto-save, multi-provider OpenAI-compatible endpoints, and LaTeX and Astro highlighting.
- Better terminal interaction: macOS readline shortcuts, clear scrollback, tab rename and close controls, safe file-path pasting, and a running-process close confirmation.
- Nix and NixOS support, agent notifications and management, and Claude Code agent orchestration from the AI interface.
- UI polish across tabs, panels, the header, and sidebar, plus dynamic window titles and source-control context menus.

## Fixes

- Terminal focus, cursor placement, IME handling, workspace launch directories, PTY lifecycle behavior, and Windows path handling are more reliable.
- Editor active-file highlighting, macOS zoom behavior, file permission preservation, and the Settings window layout are corrected.
- Linux AppImage packaging avoids the Wayland and newer-Mesa EGL crash.
