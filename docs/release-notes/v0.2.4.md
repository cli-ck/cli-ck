# Oz v0.2.4

## Highlights

- A new emerald prompt-caret identity updates the application, installers, and mobile icons.
- In-app auto-update is operational: releases publish a signed updater manifest so update checks can complete.
- The TypeScript toolchain moves to the native 7.0 compiler for faster type-checking.

## Improvements

- The chat-model picker now clearly asks you to add a provider when no provider is configured, rather than appearing locked to a default model.
