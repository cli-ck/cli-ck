# Oz v0.2.5

## Highlights

- Full Language Server Protocol support adds diagnostics, hover, go-to-definition, completion, formatting, references, and rename.
- Twenty built-in server presets cover TypeScript, Rust, Python, Go, C and C++, Zig, and more. Custom language servers are also supported.
- Settings now makes agent tiles easier to activate and adds a read-only details view for built-in and custom agents.

## AI and settings

- The model catalog adds GPT-5.6, Claude Sonnet 5, and Grok 4.5 while removing deprecated or redirected models.
- Voice-input and autocomplete model pickers show only configured providers. Local whisper.cpp setup has its own reachability check.
- Chat errors now show the real provider, model, or tool failure instead of a generic error message.

## Reliability and maintenance

- The About page shows the live build version and correct website link.
- Dependency and GitHub Actions updates, component-test infrastructure, and the version-bump script improve release consistency.
