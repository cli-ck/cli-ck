# Release notes

Every published GitHub release has a versioned Markdown note in this folder.
Add `vX.Y.Z.md`, `vX.Y.Z-alpha-N.md`, or `vX.Y.Z-beta.md` before its tag is
created. The release workflow verifies the file exists and uses it as the
published GitHub release description.

Write for users: lead with the outcome, group related changes, and distinguish
new capabilities from fixes. Do not use this file for a generic installation
message or a raw commit list.
