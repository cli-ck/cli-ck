# cli-ck v0.3.0-alpha-1

> Alpha release for early customer testing. It is a pre-release and does not update stable installations automatically.

## AI workspace intelligence

- The AI Sidebar gains free Code Intel tools for call-chain tracing, exact code lookup, and change-impact analysis in the open workspace.
- Automatic model routing selects a task-appropriate tier, while task-step workers, model teams, and reliability memory improve multi-step agent work.
- Jev routing and 9Router configuration add another configurable model-routing option.

## Faster, more capable agents

- The headless agent uses less context and adds a single-shot edit path for fast, fallback-safe changes.
- Workspace-aware tools can seed linked GitHub issue context, provision agent worktrees, automate browser actions through CDP, execute preview scripts, and inspect page elements.
- Subscription login supports OpenRouter, Codex, and Claude through their CLI-based sign-in paths.

## Reliability

- On Linux Wayland sessions, cli-ck automatically disables WebKitGTK DMA-BUF rendering to avoid a compositor-specific crash.
- Coverage tolerates an unavailable headless Chrome instead of failing unrelated verification.
