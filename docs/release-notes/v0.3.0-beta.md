# cli-ck v0.3.0-beta

> Beta release for invited developers and testers. Stable installations and the normal updater remain on the last stable release.

## Beta highlights

- Open files directly at a requested line from the CLI, making editor hand-offs more precise.
- Add developer beta download support for testing prerelease desktop builds.
- Improve prerelease publishing and Windows MSI version mapping across macOS, Linux, and Windows artifacts.

## Reliability and delivery

- Refresh JavaScript, Rust, AI SDK, and build-tool dependencies while preserving the v0.3.0 feature set.
- Keep frontend size checks, cross-platform Rust checks, and coverage gates green for the beta build.
- Allow dependency validation and CI to run without requiring the private Code Intel sidecar.

## Beta notes

- This is a prerelease for invited testers.
- Report platform-specific installer, updater, terminal, editor, and AI-agent issues with operating system and reproduction steps.
